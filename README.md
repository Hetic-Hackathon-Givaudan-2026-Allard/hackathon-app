## Lancer le projet

### Prérequis :

- **Docker Desktop** (macOS, Windows) ou Docker Engine (Linux) ;
- **VS Code** et l'extension Dev Containers ;
- **GIT** configuré sur la machine (nom, e-mail, clé SSH) : VS Code copie votre .gitconfig et relaie votre agent SSH dans le conteneur.

1. Cloner le repository

```shell
git clone ""
```

2. Ouvrez le dossier du projet dans VS Code, puis F1 → Dev Containers: Reopen in Container.

3. Ouvrir le terminal et lancer la commande :

```shell
npm run dev
```
